# Shinjiru (não implementado — stub)

Provedor malaio com múltiplos data centers "offshore". **Importante**: não é
um provedor "ignora tudo" — segundo relatos de usuários e a própria empresa,
a Shinjiru responde a obrigações legais do país onde o servidor está
hospedado, mas não age automaticamente sobre notificações DMCA vindas de
EUA/Europa sem base legal local. Ou seja: mais tolerante que hosts
tradicionais, mas não uma garantia absoluta de imunidade a remoção.

## API

provisionamento automatizado de VPS (criação/gerenciamento via API). O
provisionamento parece ser feito majoritariamente pelo painel de cliente.
Antes de considerar como provider first-class, confirmar diretamente com o
suporte da Shinjiru se existe uma API de reseller/automação — caso não
exista, este provedor não se encaixa no requisito "tem API" do projeto e
deve ficar apenas como opção de VPS comprada manualmente (fora do fluxo
automatizado desta plataforma).
