# Hostinger (planos "offshore" — não implementado — stub)

Hostinger é um provedor mainstream (não é um host "DMCA-ignore" dedicado);
alguns data centers/planos são vendidos por revendedores como "offshore",
mas a Hostinger em si segue políticas de abuso padrão de mercado e responde
a notificações DMCA como qualquer host convencional.

**Recomendação**: não tratar como provedor DMCA-resistente. Só faz sentido
incluir aqui se o objetivo for apenas diversidade de datacenter/preço, não
resistência a takedown.

## API

A Hostinger possui uma API pública (hPanel API) para VPS, incluindo criação,
listagem e gerenciamento de instâncias. Antes de implementar, consultar a
documentação oficial da API da Hostinger para o schema de autenticação
(token) e endpoints de criação de VPS.
